## Why

Make the briefing application installable by another operator without inheriting
private deployment addresses, accounts, personal source names, or Git history.

## What Changes

- Export an independent MIT repository with generic source examples.
- Require explicit deployment URL and Gmail account configuration.
- Resolve Codex through a configured executable or PATH.
- Package the API's source policy and management assets; verify a clean install.
- Document setup, acceptance, known platform limitations, and skill installation.

## Capabilities

### New Capabilities
- `portable-release`: distributable source and installable API with private runtime isolation.

### Modified Capabilities

None. The cached briefing model, role separation, and source preservation remain the baseline.

## Impact

Runtime configuration, deployment templates, package metadata, CI, and documentation.
No production deployment or change to the source private repository is required.
